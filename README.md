# Toastmasters Timer

A browser-local speech timer built with HTML, CSS, and vanilla JavaScript. No frameworks, external libraries, CDNs, or backend are required.

Open index.html locally or serve the repository root with GitHub Pages.

Features include automatic green/yellow/red signals with shapes and text, continuous count-up timing, 30-second grace after maximum, optional before-minimum allowance, custom timing, editable meeting records, CSV/JPG reports, a read-aloud report, and a mobile-friendly speaker display.

Meeting data is stored in this browser's localStorage. Export reports to preserve a copy. Role presets are suggested club timings. This is a regular meeting timer, not an official contest eligibility tool. Accessibility features are included; formal WCAG conformance has not been independently verified.
